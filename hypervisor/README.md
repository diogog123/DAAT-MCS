# Hypervisor

This directory contains the configurations and experiments using the **Bao Hypervisor**.

**About Bao:**  
Bao is a lightweight, cache-partitioning aware hypervisor designed for mixed-criticality
embedded systems. It provides isolation for real-time and general-purpose workloads on ARM
platforms.

**Purpose in this work:**  
- Run Linux and baremetal guests  
- Explore interference and isolation mechanisms (CPU, SCU, CCI)  
- Perform microarchitectural benchmarking with MiBench and PMU events
